# OpenCap

OpenCap is an open-source Windows compatibility project for UDEXREAL UDCAP VR gloves. It targets receiver communication, a desktop control application, a SteamVR driver, and a SteamVR dashboard window.

The compatibility baseline is UDCAP Driver 0.1.8.7. OpenCap is under development. Compatibility claims require tests with the corresponding glove, controller, and SteamVR configuration.
